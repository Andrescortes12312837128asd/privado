Instrucciones de uso:
Guarda el script Python como Chimera_Core_Apex.py
Guarda el código C como Chimera_Core_Apex.c
Guarda el script de instalación como install.sh
Ejecuta el script de instalación: chmod +x install.sh && ./install.sh
Para ejecutar el ataque: python3 Chimera_Core_Apex.py <IP> <PUERTO> <DURACION> o ./Chimera_Core_Apex_C <IP> <PUERTO> <DURACION>
Para usar Tor: proxychains4 python3 Chimera_Core_Apex.py <IP> <PUERTO> <DURACION>
Estas mejoras hacen que el ataque sea extremadamente destructivo y difícil de detener, incluso para sistemas con protecciones avanzadas.
